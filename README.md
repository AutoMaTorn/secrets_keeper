# Secrets Keeper

Консольная программа для хранения секретов в зашифрованном виде на вашем пк. Можно добавить и потом быстро скопировать нужный секрет.

## Возможности 
- Список секретов с навигацией стрелками
- Копирование значения в буфер обмена одной клавишей
- Добавление и удаление (с подтверждением)
- Шифрование хранилища мастер-паролем
- Работает на Windows, Linux

## Безопастность
все шифруется ляляля никто это не прочитает поэтому и писать не буду 


## Установка 

Вообщем все есть в релиза но если хочется

Нужен [Dart SDK](https://dart.dev/get-dart) 3.x.

```
git clone https://github.com/AutoMaTorn/secrets_keeper/
cd secrets_keeper
dart pub get
```
апуск без сборки:
 
```
dart run
```

### Сборка исполняемого файла
 
Linux / macOS:
 
```
dart compile exe bin/secrets_keeper.dart -o build/secrets
```
 
Windows:
 
```
dart compile exe bin/secrets_keeper.dart -o build/secrets.exe
```

Программа собирается под систему, на которой выполняется команда. С Linux и macOS можно собрать версию для Linux на другой архитектуре:

```
dart compile exe --target-os=linux --target-arch=arm64 bin/secrets_keeper.dart -o build/secrets-arm64
```

Чтобы запускать командой `secrets` из любой папки на Linux:
 
```
mkdir -p ~/.local/bin
cp build/secrets ~/.local/bin/
```

## Использование
 
При первом запуске программа попросит придумать мастер-пароль и повторить его. При следующих запусках нужно ввести этот пароль (даётся три попытки).
 
| Клавиша           | Действие                              |
|-------------------|---------------------------------------|
| `↑` / `↓`         | Выбор секрета                         |
| `Enter`           | Скопировать значение в буфер обмена   |
| `a`               | Добавить секрет                       |
| `Del` / `d`       | Удалить выбранный секрет              |
| `q` / `Ctrl+C`    | Выход                                 |
 
## Где лежит хранилище
 
| Система  | Путь                                                    |
|----------|---------------------------------------------------------|
| Windows  | `%APPDATA%\secrets_keeper\vault.json`                   |
| Linux    | `$XDG_CONFIG_HOME/secrets_keeper/vault.json` или `~/.config/secrets_keeper/vault.json` |
| macOS    | `~/Library/Application Support/secrets_keeper/vault.json` |
 
Файл зашифрован, поэтому его резервную копию можно хранить где угодно — для открытия всё равно нужен мастер-пароль.
 
## Буфер обмена
 
| Система          | Что используется                         |
|------------------|------------------------------------------|
| Windows          | `clip`                                   |
| macOS            | `pbcopy`                                 |
| WSL              | `clip.exe`                               |
| Linux (Wayland)  | `wl-copy`, затем `xclip` / `xsel`        |
| Linux (X11)      | `xclip` или `xsel`                       |
| Без графики, SSH | OSC 52 — копирование через сам терминал  |
 
На Linux установите одну из утилит:
 
```
sudo apt install wl-clipboard   # Wayland
sudo apt install xclip          # X11
```
 
> ⚠️ Скопированный секрет остаётся в буфере обмена. На Windows он также попадает в журнал буфера (`Win+V`), а при включённой синхронизации — в облако. Журнал можно отключить в «Параметры → Система → Буфер обмена».
